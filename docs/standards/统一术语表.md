# eoto 统一术语表与经批准词汇库

本文档是 `eoto` 项目的唯一术语权威来源（Single Source of Truth）。所有项目文档、架构设计、需求说明与代码注释必须统一使用本表中的标准术语。

新增核心概念时，文档作者或 `eoto-doc-steward` 必须先将术语提交至本表，再在业务文档中使用。

---

## 二、架构与研发术语

| 标准术语 | 英文 / 标识 | 词性 | 唯一批准释义 | 禁止混用的别名 |
| :--- | :--- | :--- | :--- | :--- |
| 子 Agent | Sub-Agent | 名词 | 隶属于特定业务域的执行代理，具备操作本业务系统工具的能力。 | 子智能体、业务机器人、分支 Agent |
| 协同入口平台 | Collaboration Host Platform | 名词 | 企业日常使用的外部聊天与办公平台，特指钉钉、飞书与企业微信。 | IM 平台、聊天工具、壳子平台 |
| 钉钉 / 飞书 / 企业微信 | DingTalk / Feishu / WeCom | 专有名词 | 三大目标协同入口平台的标准全称。 | 企微、WXWork |
| 主数据模型 | Master Data Model | 名词 | 全平台共享的核心数据库 Schema，锁死跨系统实体字段与状态。 | 共享表、统一库、核心表结构 |
| 契约规范 | API / MCP Contract | 名词 | 各子系统对外暴露的接口协议与工具调用标准。 | 接口文档、调用协议、工具契约 |
| 业务状态机 | Business State Machine | 名词 | 后端控制核心业务实体状态流转的确定性逻辑引擎。 | 状态流转引擎、后端状态逻辑 |
| 标准工具接口 | Standard Tool Interface | 名词 | 供 `eoto Core` 与子 Agent 调用的标准化后端操作接口（Tools）。 | 工具集、AI 接口、操作 API |
| 人工确认 | Human-in-the-loop (HITL) | 名词 | 运行态对资金变动、库存红线与核心审批强制触发的人工复核机制。 | 人工介入、人工兜底、人工干预 |
| 底层主干源码 | Core Trunk Source Code | 名词 | 面向所有客户保持绝对标准化的核心代码库。 | 核心源码、主干代码、标准代码 |
| 编程 Agent | Coding Agent | 名词 | 在研发阶段并行编写业务模块代码的开发代理。 | 开发 AI、写码 Agent |
| 测试 Agent | Testing Agent | 名词 | 在研发阶段编写并执行自动化集成测试的质量保障代理。 | QA Agent、测验 AI |
| 主仓库 | Main Repository | 名词 | `eoto` 仓库。存放规范、文档、主数据模型与契约规范，不存放业务实现代码。 | 母仓库、总仓库、规范库、umbrella 仓库 |
| 产品仓库 | Product Repository | 名词 | 实现单个产品或 SDK 的独立代码仓库，例如 `eoto-sales`。 | 子仓库、业务仓库、模块仓库 |
| 契约版本 | Contract Version | 名词 | 主仓库发布的主数据模型与契约规范版本，使用 `YYYY-MM-DD` 格式命名。 | 协议版本、Schema 版本、接口版本 |

## 三、核心主数据实体

所有业务模块与数据库设计必须使用以下六个标准实体名称：

| 标准实体 | 英文标识符 | 唯一批准释义 | 禁止混用的别名 |
| :--- | :--- | :--- | :--- |
| 员工 | `Employee` | 企业内部成员，同步自协同入口平台的组织架构。 | 人、人员、用户（指内部员工时） |
| 部门 | `Department` | 企业内部组织单元，同步自协同入口平台。 | 组织、团队、小组 |
| 客户 | `Customer` | 购买企业产品或服务的外部商业实体与联系人。 | 甲方、买家、商业伙伴 |
| 商品 | `Product` | 企业销售、采购或库存管理的标准标的物（SKU）。 | 货品、物料、产品（在进销存语境下） |
| 订单 | `Order` | 记录销售成交或采购履约明细的核心单据。 | 单子、合同单、交易单 |
| 资金流水 | `CashFlow` | 记录应收、应付、收款与付款明细的经营资金记录。 | 账目、流水账、财务记录 |

## 五、经批准的核心动词表

编写文档时，优先使用下列标准动词，避免同义词漂移与名词化表达：

| 标准动词（中文） | 标准动词（英文） | 批准含义 | 避免使用的替代词 |
| :--- | :--- | :--- | :--- |
| 调度 | dispatch | `eoto Core` 向子 Agent 分配任务 | 派发、分派、指派、驱使 |
| 接入 | connect | `eoto Link` 对接外部协同入口平台 | 挂载、寄生（技术文档中）、打通（特指连接动作时） |
| 锁定 | lock | 锁死数据库 Schema 或在下单后锁定库存 | 冻结、占住、锁死（正式动作描述） |
| 扣减 | deduct | 在发货或出库时减少可用库存数量 | 减去、消减、扣除 |
| 校验 | verify | 验证数据一致性、并发安全或对账结果 | 核验、检验、进行校验 |
| 核算 | calculate | 计算单笔订单毛利、应收应付或现金流 | 算清、测算、统计 |
| 配置 | configure | 在 `eoto Studio` 中设置规则、工作流或插件 | 搭建、部署（特指规则配置时）、set up |
| 导出 | export | 按标准格式输出数据以对接外部会计软件 | 抽离、倒出、输出（特指文件导出时） |
| 确认 | confirm | 由人在高危动作前执行人工复核与批准 | 拍板、兜底、点确认 |
| 审查 | audit | 由 `eoto-doc-steward` 检查文档是否符合术语与写作规范 | 过目、看看、核查 |
