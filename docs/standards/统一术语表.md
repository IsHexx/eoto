# eoto 统一术语表与经批准词汇库

本文档是 `eoto` 项目的唯一术语权威来源（Single Source of Truth）。所有项目文档、架构设计、需求说明与代码注释必须统一使用本表中的标准术语。

新增核心概念时，文档作者或 `eoto-doc-steward` 必须先将术语提交至本表，再在业务文档中使用。

## 二、架构与研发术语

| 标准术语 | 英文 / 标识 | 词性 | 唯一批准释义 | 禁止混用的别名 |
| :--- | :--- | :--- | :--- | :--- |
| 主 Agent | Main Agent | 名词 | `eoto Core` 中理解自然语言指令、拆解跨子系统任务，并通过对外接口调度子 Agent 的执行代理。 | 总 Agent、调度 AI |
| 子系统 | Subsystem | 名词 | 拥有独立数据库、业务状态机、子 Agent 与对外接口的业务系统。子系统按管理对象划分：CRM 子系统管理人，ERP 子系统管理物，经营财务子系统管理钱。 | 业务域、业务模块、业务能力、模块 |
| 子 Agent | Sub-Agent | 名词 | 隶属于特定子系统的执行代理，通过本子系统的标准工具接口操作业务。 | 子智能体、业务机器人、分支 Agent |
| 对外接口 | Subsystem Interface | 名词 | 子系统与外部交互的唯一出口，包含 API、MCP 工具与领域事件，定义在契约规范中。 | 开放接口、出口 API、网关接口 |

| 资金对象 | Financial Record | 名词 | 记录资金变动的业务数据，包括回款计划、应收、收款、付款与资金流水。只由经营财务子系统写入。 | 财务数据、账目、钱的数据 |
| 主数据归属 | Data Ownership | 名词 | 每个主数据实体只由一个子系统或 `eoto Core` 持有与写入的规则。其他方通过实体 ID 引用，并通过持有方的对外接口读取。 | 数据主权、数据所有权 |

| 业务状态机 | Business State Machine | 名词 | 后端控制核心业务实体状态流转的确定性逻辑引擎。 | 状态流转引擎、后端状态逻辑 |

| 人工确认 | Human-in-the-loop (HITL) | 名词 | 运行态对资金变动、库存红线与核心审批强制触发的人工复核机制。 | 人工介入、人工兜底、人工干预 |
| 底层主干源码 | Core Trunk Source Code | 名词 | 面向所有客户保持绝对标准化的核心代码库。 | 核心源码、主干代码、标准代码 |

## 三、核心主数据实体

所有代码包与数据库设计必须使用以下七个标准实体名称。归属方为初始方案，在主数据模型设计时最终确认：

| 标准实体 | 英文标识符 | 唯一批准释义 | 归属方 | 禁止混用的别名 |
| :--- | :--- | :--- | :--- | :--- |
| 员工 | `Employee` | 企业内部成员，同步自协同入口平台的组织架构。 | `eoto Core` | 人、人员、用户（指内部员工时） |
| 部门 | `Department` | 企业内部组织单元，同步自协同入口平台。 | `eoto Core` | 组织、团队、小组 |
| 客户 | `Customer` | 购买企业产品或服务的外部商业实体与联系人。 | CRM 子系统 | 甲方、买家、商业伙伴 |
| 商品 | `Product` | 企业销售、采购或库存管理的标准标的物（SKU），包括实物商品与服务类商品。 | ERP 子系统 | 货品、物料、产品（在进销存语境下） |
| 销售订单 | `SalesOrder` | 记录企业向客户销售商品或服务的交易单据，包括周期性订单与一次性订单。 | CRM 子系统 | 单子、合同单、交易单、销售单 |
| 采购订单 | `PurchaseOrder` | 记录企业向供应商采购商品的交易单据。 | ERP 子系统 | 采购单、进货单 |

正文中单独使用订单时，指销售订单。例如订单生命周期与单笔订单毛利均指销售订单。
| 资金流水 | `CashFlow` | 记录应收、应付、收款与付款明细的经营资金记录。 | 经营财务子系统 | 账目、流水账、财务记录 |

## 四、业务与战略术语

| 标准术语 | 英文 / 标识 | 词性 | 唯一批准释义 | 禁止混用的别名 |
| :--- | :--- | :--- | :--- | :--- |
| 经营财务 | Operational Finance | 名词 | 面向经营决策的业务财务领域，覆盖应收应付、催款提醒、单笔订单毛利与现金流预测。 | 业务财务、业财一体（作模块名词时）、老板财务 |
| 核算报税 | Statutory Accounting and Tax Filing | 名词 | 总账、会计凭证与税务申报领域。`eoto` 明确不自研该领域，仅提供标准导出接口。 | 记账报税、传统财务、做账报税 |
| 订单生命周期 | Order Lifecycle (Order-to-Cash) | 名词 | 一笔订单从报价、签约、履约到回款的完整业务链路。 | 销售到交付闭环、签单交付闭环、业务闭环（特指此链路时） |

| 周期性订单 | Recurring Order | 名词 | 按月、按季或按年重复生成服务任务与应收的订单。 | 循环订单、订阅单、续期单 |

| 服务合同 | Service Contract | 名词 | 客户与代理记账企业签订的周期性服务合同。CRM 子系统根据服务合同创建周期性订单。 | 代账合同、服务协议 |

## 六、经批准的核心动词表

编写文档时，优先使用下列标准动词，避免同义词漂移与名词化表达：

| 标准动词（中文） | 标准动词（英文） | 批准含义 | 避免使用的替代词 |
| :--- | :--- | :--- | :--- |
| 调度 | dispatch | `eoto Core` 向子 Agent 分配任务 | 派发、分派、指派、驱使 |
| 接入 | connect | `eoto Link` 对接外部协同入口平台 | 挂载、寄生（技术文档中）、打通（特指连接动作时） |
| 锁定 | lock | 在签约后锁定库存，或锁定已发布契约版本的内容 | 冻结、占住、锁死（正式动作描述） |
| 扣减 | deduct | 在发货或出库时减少可用库存数量 | 减去、消减、扣除 |
| 校验 | verify | 验证数据一致性、并发安全或对账结果 | 核验、检验、进行校验 |
| 核算 | calculate | 计算单笔订单毛利、应收应付或现金流 | 算清、测算、统计 |
| 配置 | configure | 在 `eoto Studio` 中设置规则、工作流或插件 | 搭建、部署（特指规则配置时）、set up |
